Brief Overview

My name is Mauricio Garcia Villanueva and I am a Mexican-American software engineer and data scientist based in Austin, TX. I have a strong passion for using technology to improve people's quality of life, and I'm particularly interested in the potential of artificial intelligence and machine learning to revolutionize the ways we live and work.

The two languages I love working with the most are Java and Python. I have used these two in a plethora of environments; for example, I have used Java to design REST APIs while being mentored by Netflix as well as robotics for my own robotics team, and I have used Python to practice competitive coding/algorithms and work on machine learning tasks.
